# 指标与图形编码

统计单位为“源请求记录—商品配对”。每条请求 s 的曝光、点击、购买反馈分别去重为 I_s、C_s、P_s。

| 指标 | 公式 |
| --- | --- |
| 曝光配对 E | Σ count(I_s) |
| 匹配点击 C | Σ count(I_s ∩ C_s) |
| 匹配购买反馈 P | Σ count(I_s ∩ P_s) |
| 点击配对占比 | C / E |
| 购买反馈配对占比 | P / E |

分母为零返回 null，显示“—”。整体比率先求和分子分母，再相除，不平均商品百分比。购买反馈无点击仍保留，不能强制使用三重交集画漏斗。曝光外反馈、重复列表项分别审计。反馈不是支付、金额或独立人数。

搜索柱宽深固定、高度按曝光线性缩放并从零起；默认范围自适应，可用全局量尺。类目按当前范围曝光排序，主图绘制预算保留完整类目列表，不人为合并为 OTHER。商品标记 X=曝光、Y=一种反馈占比，固定深度和大小，自动横轴非零起点明确标记。A/B 使用相同 0—100% 量尺，整体差值为 100 × (rate_B − rate_A) 个百分点。

曝光流向逐级拆分同一 E，代表商品加余量守恒。类目体检中曝光份额为 E_c/E、反馈份额为 N_c/N，反馈率为 N_c/E_c；N 为 C 或 P。总反馈为零时份额为空。集中度按同一曝光排序累计，K80 为达到完整 E 的 80% 的最小类目数。

商品诊断的参照为同 scope、split、原始类目的完整计数减去自身。商品与参照曝光均达到门槛（30/100/300，默认100），参照对应反馈≥10，本商品占比≤参照×0.8 才触发该指标复核提示。未知类目、零曝光或无参照不判断。门槛只影响解释，不改变分母。

优化罗盘矩形面积 = 容器面积 × E_i / 图内正曝光总和；切指标不改面积。颜色表示复核状态，位置无业务含义。候选预算与覆盖率必须同时展示，图内候选不代表全部商品。

3D/2D/详情/导出共享 scope 与 ViewModel。源文本只作文本，时间仅保留相对索引，不恢复绝对日期或虚构事件顺序。手工算例见 [golden fixture](../fixtures/golden.synthetic.json)。
