# 操作指南

1. 用 `?demo=1` 打开合成演示，确认顶部“演示样本 · 非真实统计”。
2. 左侧查找框只查找查询词；点击一个查询才改变分析范围。顶部显示请求数、曝光配对和匹配点击占比。
3. 在“搜索去向”点击类目，右侧读取精确数量。柱高表示曝光，颜色识别类目；切换二维或视角不会改范围。
4. 在“曝光流向”展开类目。右侧最多五件代表商品及其余曝光合计等于类目曝光，流带不是行为时间线。
5. 在“类目体检”切换份额对照与集中度。份额与反馈率不同；K80 表示覆盖八成曝光需要的最少类目数。点类目后可进入商品诊断。
6. 在“商品表现”读取 X 曝光与 Y 一种反馈占比。自动坐标轴会调整显示范围，精确计数不变。点击重叠编号查看商品列表。
7. 在“优化罗盘”点击曝光版图中的商品：面积是图内曝光占比，橙/薄荷/灰分别表示建议检查、暂未触发、信息不足。右侧展开具体检查步骤，按需保存到复核清单。
8. 冻结 A/B 查询组后，在“两组对照”用相同量尺比较。差值为 B−A 个百分点，重叠请求另列，不作随机实验解释。
9. 用“数据与口径”“证据”检查输入及分子分母；复核清单保留当时 scope、版本与备注。保存由 API 确认，浏览器会话 cookie 区分归属。
10. 导出当前范围或对照。显示 TopK、图内聚焦不会裁剪导出的统计范围；超出预算会明确报错，需缩小查询范围后重试。

桌面为单屏工作台，长列表在面板内滚动；手机用“图表 / 查询 / 详情”切换。“商家解读”和“精确读数”以弹层打开，可按 Escape 关闭。

自有日志从“导入数据”上传符合 [输入 schema](../contracts/normalized.schema.json) 的 JSON，模式使用 `authorized_private`。字段和反馈列表缺失不能当作空值；只导入有权处理的搜索日志。只有订单流水无法支持曝光与点击分析。
